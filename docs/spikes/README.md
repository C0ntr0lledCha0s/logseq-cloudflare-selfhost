# Spikes

Write-ups from `lane-spike`, named `YYYY-MM-DD-slug.md`. Each one answers its questions with evidence and ends with a call: build, don't build or revisit. Durable facts a spike settles (platform limits, costs, what upstream can do) also go into `docs/solutions`, so later lanes don't research them again. `docs/spike-results.md` holds the earlier, hand-run deployment checks.
